# MiniLang — интерпретируемый язык программирования на Rust

Учебный интерпретатор простого языка программирования **MiniLang**, написанный на языке Rust. Проект демонстрирует полный цикл обработки исходного кода: лексический анализ, синтаксический разбор, построение абстрактного синтаксического дерева (AST) и выполнение программы.

## Реализованные возможности
* **Типы данных:** целые числа (`i64`), логические значения (`true`, `false`), строки.
* **Переменные:** объявление через `let` и изменение значений существующих переменных.
* **Арифметика:** `+`, `-`, `*`, `/`, `%`, унарный минус `-` и группировка скобками `(...)`.
* **Операции сравнения:** `==`, `!=`, `>`, `<`, `>=`, `<=`.
* **Условные конструкции:** `if условие { ... } else { ... }` (блок `else` является необязательным, поддерживаются цепочки `else if`).
* **Циклы:** `while условие { ... }` со встроенной защитой от бесконечного цикла (лимит в 10 000 итераций).
* **Обработка ошибок:** понятные сообщения об ошибках лексики, синтаксиса и времени выполнения (включая проверку типов условий и деление на ноль).

## Требования для запуска
* Установленный компилятор **Rust** и менеджер пакетов **Cargo** (версия 1.70 и выше).

## Инструкция по запуску
1. Клонируйте репозиторий или скачайте исходный код и перейдите в корневую папку проекта:
   ```bash
   cd MiniLang
   ```
2. Запустите интерпретатор с передачей пути к файлу программы (файлы программ должны иметь расширение `.rpotop`):
   ```bash
   cargo run -- examples/01_basics_and_if.rpotop
   ```

## Примеры программ (папка `examples/`)
* `examples/01_basics_and_if.rpotop` — демонстрация переменных, математики, сравнений и выполнения ветки `if`.
* `examples/02_else_branch.rpotop` — демонстрация выполнения ветки `else` и конструкции `if` без `else`.
* `examples/03_while_loop.rpotop` — демонстрация работы цикла `while` и изменения переменных.
* `examples/04_errors.rpotop` — демонстрация перехвата ошибки при передаче числа вместо логического значения в условие `if`.
* `examples/05_infinite_loop.rpotop` — демонстрация срабатывания защиты от бесконечного цикла.
